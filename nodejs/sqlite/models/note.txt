🧠 Here's the breakdown:
Promises with .then().catch() or async/await:

If a function returns a promise, you can use .then() and .catch() or async/await with try/catch.

This works for functions like MongoDB queries, HTTP requests, etc., that return promises.

Callback-based functions:

If a function uses callbacks (like db.run() in SQLite), you need to use callbacks. Using try/catch or .then().catch() doesn't work for these because they're not returning a promise.

✅ Example Breakdown with Callback:
In your case, the createBlog function uses a callback to handle the result, so you'd handle it like this:

js

// Callback style
createBlog('My New Blog', 'Content of the blog', 1, (err, lastID) => {
  if (err) {
    console.error('Error creating blog:', err);
  } else {
    console.log('Blog created with ID:', lastID);
  }
});
You can't use async/await directly here since it doesn't return a promise.

🎯 Solution: Convert Callback to Promise (Optional)
If you want to use async/await or .then(), you can convert the callback-based function to return a promise.

Here's how you can wrap your createBlog function in a promise:

js

Edit
const createBlog = (title, content, authorId) => {
  return new Promise((resolve, reject) => {
    db.run(
      `INSERT INTO blogs (title, content, author_id) VALUES (?, ?, ?)`,
      [title, content, authorId],
      function (err) {
        if (err) {
          reject(err); // Reject the promise if there's an error
        } else {
          resolve(this.lastID); // Resolve the promise with last inserted ID
        }
      }
    );
  });
};
Now you can use async/await or .then().catch() with this function:

// Using async/await
const createBlogAsync = async () => {
  try {
    const lastID = await createBlog('My New Blog', 'Content of the blog', 1);
    console.log('Blog created with ID:', lastID);
  } catch (err) {
    console.error('Error creating blog:', err);
  }
};

// Or using then/catch
createBlog('My New Blog', 'Content of the blog', 1)
  .then(lastID => console.log('Blog created with ID:', lastID))
  .catch(err => console.error('Error creating blog:', err));
📅 Conclusion:
Callback functions: Use callbacks to handle results.

Promises: Use .then()/.catch() or async/await when dealing with promises.

If you want to mix styles (async/await with a callback), convert the callback to a promise, as shown above.
